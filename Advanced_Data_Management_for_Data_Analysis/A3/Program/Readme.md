how to run the program:

1.Download and unzip "ADM-2024-Assignment-3-data-TPCH-SF-1", and place the files in the "data" folder of the program.

Use this command to encode: 

python program.py en CompressionTechinique(bin/rle/dic/for/dif) data_type(int8/16/32/64/string) file_path(data/xxx)

Use this command to decode: 

python program.py de CompressionTechinique(bin/rle/dic/for/dif) data_type(int8/16/32/64/string) file_path(results/xxx)

If necessary, you need to use PIP to download the necessary libraries.
